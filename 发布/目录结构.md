# 发布包目录结构

> 兴安盟 AGC 子站联调仿真器 — Docker Desktop 部署包（约 187MB）。
> 部署 / 恢复 / 验证步骤见 [readme.md](readme.md)，本文件只描述结构与各条目用途。

```
发布/                                ← 本包根目录（总量约 187MB）
│
├── readme.md                        # 部署总说明：五步部署、恢复链、实测坑、补丁清单、DUT 对接（从这里开始读）
├── 目录结构.md                      # 本文件
│
├── net.sql                          # net 库权威快照（65K，2026-11-20 13:20 导出自 10.0.0.9 mysql84）
│                                    #   含 CREATE DATABASE，恢复部署用这一份（步骤见 readme §部署步骤 3）
│
├── ems-simulate-xam-image.tar       # 仿真器镜像 ems-simulate:xam 导出包（109MB，OCI 格式）
│                                    #   ImageID 9fca64e11495，含全部 4 处本地补丁，docker load 导入
│
├── ems-simulate-docker/             # 运行目录（178K）——compose 在此目录内执行，相对挂载才有效
│   ├── docker-compose.yml           # 编排：端口发布 10.0.0.7:502(Modbus)、10.0.0.7:2404(IEC104)、
│   │                                #   127.0.0.1:8991(REST/Web)；挂载 ./data 与 ./config.ini(:ro)
│   ├── config.ini                   # 监听/数据库配置（LF 行尾）：host=10.0.0.9 → 远端 mysql84
│   ├── xamapi-local.py              # 本机 API 辅助脚本（UTF-8 安全）
│   │                                #   子命令：start / autoread / gi / vals / write / restart
│   ├── data/
│   │   └── point_csv/               # 运行时落盘兜底目录（当前为空，容器写 CSV 用）
│   └── dumps/                       # 历史备份（权威快照在包根 net.sql）
│       ├── net_dump-20261120-release.sql    # 数据库切换前（本机 mysql84）的发布时点快照
│       ├── net_dump-final-20261120.sql      # 2026-11-20 迁移完成时的快照
│       └── build.log                        # 本机镜像构建日志（重建时可对照）
│
└── ems_simulate-src/                # 完整源码树（78MB，上游 GPL 项目 + 4 处本地补丁）
    ├── Dockerfile                   # 镜像构建脚本（两段式：venv 构建 → slim 运行层）
    ├── requirements-docker.txt      # 冻结依赖清单（c104/pydnp3-pure 除外）
    ├── wheels/                      # ⚠ 离线构建关键物料，勿删：
    │                                #   c104-2.2.2-cp312-cp312-linux_x86_64.whl（git 依赖预编译）
    │                                #   pydnp3_pure-0.1.0-py3-none-any.whl
    ├── start_back_end.py            # 后端启动入口（镜像 CMD）
    ├── pyproject.toml / uv.lock     # Python 项目定义
    ├── src/                         # 后端源码（FastAPI）——4 处「本地补丁」注释位置：
    │                                #   device/core/point/point_manager.py（①）
    │                                #   device/core/slave_manager.py（②）
    │                                #   data/service/slave_service.py（③）
    │                                #   data/service/yc_service.py + yt_service.py（④）
    ├── front/ / www/                # Vue3 前端源码 / 已构建产物
    ├── docs/                        # 上游文档站源（28MB，含 vitepress）
    ├── resources/                   # 上游静态资源（31MB）
    ├── tests/ / scripts/ / plan/    # 上游测试、脚本、规划文档
    ├── src-tauri/ / debian/         # 上游桌面打包 / deb 打包物料（本包用不到，随源码保留）
    ├── data/                        # 源码仓内的示例数据与 schema
    │   ├── ems_schema.sql
    │   └── point_csv/
    └── .github/                     # 上游 CI workflow
```

## 快速对照

| 要做什么 | 用哪个文件 |
|---|---|
| 部署 / 恢复 / 验证 | `readme.md`（五步部署 + 恢复链） |
| 恢复数据库 | `net.sql`（权威）或 `ems-simulate-docker/dumps/` 下的历史快照 |
| 导入镜像 | `ems-simulate-xam-image.tar` |
| 日常操作仿真器 | `ems-simulate-docker/xamapi-local.py` |
| 重建镜像 / 二次开发 | `ems_simulate-src/`（注意 `wheels/` 勿删、补丁注释勿丢） |
