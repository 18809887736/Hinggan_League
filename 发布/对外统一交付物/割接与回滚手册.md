# 割接与回滚手册（DUT 由 10.0.0.9 → 目标机）

前提：目标机已按《部署说明.md》完成部署，Web 界面可开。

## 一、割接

1. **停旧仿真**：10.0.0.9 上 `cd ~/hinggan/ems_simulate && docker compose stop`（mysql84 等其他容器不动）。
2. **备份 DUT 实时库**：
   ```
   cp /home/syth/QCzt2016/database/qplantagcrtdb.db /home/syth/QCzt2016/database/qplantagcrtdb.db.bak-$(date +%Y%m%d)-toTarget
   ```
3. **改 DUT PORT_NET**（sqlite3，`<目标机IP>` 用 set-site 打印的值，当前示例 10.0.0.7）：
   ```
   sqlite3 /home/syth/QCzt2016/database/qplantagcrtdb.db \
     "UPDATE PORT_NET SET remote_address='<目标机IP>' WHERE remote_address='10.0.0.9';"
   sqlite3 /home/syth/QCzt2016/database/qplantagcrtdb.db "SELECT * FROM PORT_NET;"
   ```
4. **重启 DUT**（顺序不可乱）：
   ```
   ps -ef | grep qplantagcserver        # 记下全部相关 pid
   kill <pid>                            # 若进程以 root 启动需 sudo -S kill
   # 静置 ≥80 秒（60s 偶发卡死 installTranslator，80s 实测稳）
   cd /home/syth/QCzt2016/build
   export DISPLAY=:0 XAUTHORITY=/home/syth/.Xauthority
   nohup ./qplantagcserver > ~/qserver.log 2>&1 < /dev/null &
   ```
   等初始化日志出现 `rtdbManager start`（偶有 1~2 分钟慢启动，勿过早判死）。
5. **验证**（三条全过即割接成功）：
   - 连接：DUT 上 `ss -tn | grep <目标机IP>` 应见 502、2404 两条 ESTAB；目标机上 `netstat -an | findstr <DUT_IP>` 应见一条到 DUT:2404。
   - 通道状态：`sqlite3 ...qplantagcrtdb.db "SELECT yx_num,yx_data FROM YX_DATA WHERE yx_num IN (101,102,107);"` 三个都应为 **65**。
   - 数据：目标机改一个遥测值（Web 或 write-baseline），40~60s 后 DUT 库 `YC_DATA` 对应行变化。

## 二、回滚

1. DUT：`UPDATE PORT_NET SET remote_address='10.0.0.9' WHERE remote_address='<目标机IP>';`（或直接用步骤 2 的备份覆盖实时库）。
2. 10.0.0.9：`cd ~/hinggan/ems_simulate && docker compose restart`，随后按既有恢复链（start×3 → 容器内 socket 实测 502/2404 → autoread/gi → 重写点值）。
3. DUT 重启（同割接步骤 4：kill → 静置 ≥80s → 拉起）。

## 三、日常运维速查（目标机）

| 场景 | 操作 |
|---|---|
| 重启仿真 | `scripts\stop.ps1` → `scripts\start.ps1`（**之后必须重启 DUT**，见上） |
| 改点值 | Web 界面或 `tools\ems_local.py write <plc\|ncs\|master> <大写点号> <值>` |
| 总召唤 | `tools\ems_local.py gi master`（主站收值靠总召） |
| 看 104/Modbus 报文 | `log\iec104.log`、`log\PLC-仿真\`、Web 界面报文页 |
| DUT 侧查询 | `sqlite3 /home/syth/QCzt2016/database/qplantagcrtdb.db "SELECT ... FROM YC_DATA WHERE yc_num=...;"` |
